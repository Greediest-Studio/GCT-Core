# Cloud Giant Crystal

Editable Blockbench project: `cloud_giant_crystal.bbmodel`

Runtime exports:

- Geometry: `geo/cloud_giant_crystal.geo.json`
- Animations: `animations/cloud_giant_crystal.animation.json`
- Texture: `textures/entity/cloud_giant_crystal.png`

The default pose and texture represent a drained, dormant crystal. The model uses a compact square cage, a suspended faceted core, and four orbiting shards.
